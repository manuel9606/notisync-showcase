## Descripción

NotiSync es una plataforma SaaS desarrollada para centralizar, visualizar y gestionar notificaciones de pagos digitales mediante una interfaz web.

**Sitio web:** https://notisync.net

## Tecnologías utilizadas

- **Backend:** Node.js y Express.js
- **Frontend:** EJS, HTML, CSS y JavaScript
- **Base de datos:** MySQL
- **Integraciones:** Pushbullet API y Mercado Pago
- **Arquitectura:** Aplicación web con renderizado del lado del servidor

## Funcionalidades principales

- Registro y autenticación de usuarios.
- Panel de administración con información de pagos en tiempo real.
- Historial de transacciones y filtros de búsqueda.
- Registro manual de pagos.
- Integración con servicios externos mediante APIs.
- Gestión de planes y suscripciones.

## Arquitectura general

La plataforma utiliza Node.js y Express para procesar las solicitudes, renderizar vistas EJS y gestionar la lógica de negocio. MySQL permite almacenar la información y las integraciones externas facilitan los flujos de notificaciones y suscripciones.
